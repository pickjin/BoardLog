# 01. Product Discovery

상태: PHASE 1 완료 (2026-10-30). 결정 근거는 [decision-log.md](./decision-log.md) 참조.

## 1. 문제 정의

보드게임 이용자는 두 가지 기록을 따로 관리하거나 아예 남기지 않는다.

- **플레이 기록:** 누가 이겼는지, 누구와 했는지는 모임이 끝나면 사라진다. 기록하더라도 한 명이 남긴 결과를 다른 참여자가 다시 입력해야 한다.
- **컬렉션:** 무엇을 가지고 있는지, 누구에게 빌려줬는지, 어디에 보관했는지를 기억에 의존한다.

두 기록은 같은 대상(게임)에 대한 정보인데 서로 연결되지 않는다. (가정: 실제 이용자 조사 데이터 없음)

## 2. 목표 사용자 (D-001)

동등한 두 축으로 정의한다.

| 축 | 사용자 | 대표 상황 |
|---|---|---|
| 기록 | 모임의 기록 담당자 | 게임이 끝난 뒤 2~3분 안에 결과를 남기고 참여자에게 공유 |
| 컬렉션 | 개인 컬렉터 | 소장 게임 등록, 대여·보관 위치 관리, 목록 공유·도록 출력 |

비대상(현 단계): 보드게임 카페·동호회 운영자(B2B). 백엔드와 다중 사용자 권한이 필요해 E-001과 충돌.

## 3. 핵심 가치 (D-002, D-003)

**"게임 하나를 중심으로, 내가 가진 것과 내가 한 것이 이어진다."**

- 게임 상세 화면이 허브다: 소장 정보 + 플레이 이력 + 승률 + 함께한 사람.
- 허브는 **정규화한 게임 이름**으로 기록을 묶어 계산한다. 저장 구조는 바꾸지 않는다.
  - 소장 게임: 컬렉션에 표시, 허브 제공
  - 소장하지 않은 게임(카페·친구 게임): 컬렉션에 섞지 않고 게임 탭의 "기록만 있는 게임" 구역에 표시, 허브 제공
  - 나중에 구입해 등록하면 이름이 같은 이전 기록이 같은 허브에 모인다
  - 공유 링크로 받은 기록도 같은 규칙으로 허브에 모인다
- 정규화 규칙: PHASE 2에서 확정 (TBD)
- 표기 차이로 갈라진 허브 합치기: TBD-001

## 4. MVP 범위 (D-007)

### 4.1 유지 (기존 기능, 확장 동결)

확장 동결 = 버그 수정과 결정 사항 반영 외의 기능 추가를 하지 않는다. 측정 결과(4주)에 따라 정리 여부를 다시 결정한다.

| 축 | 기능 |
|---|---|
| 기록 | 기록 입력(결과 자동 판정, 최근 게임 우선, 최근 함께한 사람 칩), 결과 공유 시트, 공유 링크(받은 사람이 자기 기록에 추가), 플레이 기록 탭, 수집가 레벨 |
| 컬렉션 | 게임 등록(수동, 시드 DB 300개 검색, 박스 사진 일괄 인식), 소장 상태 7종, 구매가·정가·시세 입력, 보관 장소, 상태, 태그, PDF 도록, 카톡 목록 공유 |
| 공통 | 로컬 계정(회원가입·로그인, 기기 간 동기화 없음), 게스트 모드, JSON 백업·복원, 예시 데이터 지우기, 홈 화면 설치(PWA) |

### 4.2 신규

| ID(가칭) | 기능 | 근거 |
|---|---|---|
| NEW-1 | 게임 허브: 게임 상세에 플레이 이력·승률·함께한 사람, 게임 탭 "기록만 있는 게임" 구역 | D-002, D-003 |
| NEW-2 | 측정: GA4(재방문·행동 이벤트), Vercel Web Analytics(방문 추세) | D-004, D-005, D-006 |
| NEW-3 | 개인정보 처리 고지 문구 | D-005 |

요구사항 ID는 PHASE 2에서 정식 부여한다.

### 4.3 MVP 밖

- 백엔드, 기기 간 동기화, 서버 계정 (E-001, E-002)
- 사람 단위 데이터(친구 프로필), 활동 타임라인 (D-002 대안으로 기각)
- 외부 시세·BGG 실데이터 연동
- 카페·동호회용 기능

## 5. 성공 기준 (D-006)

| 항목 | 정의 |
|---|---|
| 지표 | 첫 방문 후 28일 안에 다시 와서 기록(`play_saved`)을 1회 이상 남긴 비율 |

| 최소 표본 | 신규 사용자 50명 (95% 신뢰 오차 ±11%p, 계산값) |

판정 후 행동은 decision-log.md D-006 참조.

## 6. 가정과 위험

| 구분 | 내용 |
|---|---|
| 가정 | 보드게임 모임 주기는 격주~월 단위다 |
| 가정 | 한 명이 기록하면 공유 링크로 다른 참여자가 앱을 연다 |
| 가정 | 재방문 기준 25%, 보조 기준 10% |
| 위험 | 두 축 동등(D-001)으로 1인 개발 자원이 분산된다 |
| 위험 | 측정 이전에는 확장 동결 기능의 실제 사용 여부를 알 수 없다 |
| 위험 | GA4 쿠키 사용에 따른 고지 의무의 법적 범위가 확인되지 않았다 (TBD-005) |
